# 股票振幅监控程序

基于富途API的股票振幅监控工具，可实时监控指定股票的振幅变化，当一小时振幅小于2%时发出声音提醒。

## 功能特点

- 📊 实时监控股票价格和振幅
- 🔄 支持多股票同时监控
- 🔔 振幅过低时声音提醒
- ⚙️ 可配置监控参数
- 💾 价格历史数据管理

## 安装依赖

```bash
pip install -r requirements.txt
```

## 配置API密钥

1. 在富途开放平台申请API密钥和访问令牌
2. 编辑 `config.json` 文件，填入您的API信息：

```json
{
  "futu_api": {
    "host": "https://openapi.futunn.com",
    "api_key": "YOUR_ACTUAL_API_KEY",
    "access_token": "YOUR_ACTUAL_ACCESS_TOKEN"
  }
}
```

## 使用方法

1. 运行程序：
```bash
python stock_amplitude_monitor.py
```

2. 输入要监控的股票代码（用逗号分隔）：
```
请输入股票代码: 00700,00941,000001
```

3. 程序将开始监控，当股票一小时振幅小于2%时会发出声音提醒

## 配置说明

### config.json 参数

- `amplitude_threshold`: 振幅阈值（默认0.02，即2%）
- `check_interval`: 检查间隔（默认60秒）
- `sound_enabled`: 是否启用声音提醒
- `sound_frequency`: 声音频率（Hz）
- `sound_duration`: 声音持续时间（毫秒）
- `sound_repeat`: 声音重复次数

### 股票代码格式

- 港股：如 `00700`（腾讯控股）
- A股：如 `000001`（平安银行）
- 美股：如 `AAPL`（苹果公司）

## 注意事项

1. 确保网络连接正常，能够访问富途API
2. 检查API密钥和访问令牌是否有效
3. 程序需要在Windows系统上运行（声音提醒功能）
4. 监控频率不宜过高，避免API调用限制

## 停止监控

按 `Ctrl+C` 可停止监控程序
